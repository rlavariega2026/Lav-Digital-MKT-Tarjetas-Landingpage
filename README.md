# LAV Digital MKT — Landing de tarjetas digitales

Landing page adaptable a móvil y escritorio para promocionar tarjetas digitales y tarjetas físicas PVC con NFC y código QR.

## Paquetes
- $350 MXN: tarjeta digital personalizada + 1 tarjeta PVC con NFC y QR.
- $499 MXN: tarjeta digital personalizada + 2 tarjetas PVC con NFC y QR.

## Funciones
- Formulario que prepara los datos y abre WhatsApp (+52 777 107 9192); la persona debe confirmar el envío.
- Botones de WhatsApp, animaciones y menú adaptable a móvil.
- Enlace a la tarjeta de muestra: https://lavdigitalmkt.com/tarjetas/ral/ral/index.html
- Enlace a la página principal: https://lavdigitalmkt.com/

## Publicación en Hostinger
Sube el contenido del ZIP de entrega a una carpeta exclusiva dentro de `public_html` y asegúrate de que `index.html` quede directamente dentro de esa carpeta. Este repositorio no publica por sí solo a Hostinger; la carga del ZIP se realiza por separado.
